# Open this workspace in Google Antigravity

1. Extract the `CertMaster_Antigravity_Workspace.zip` archive into a local directory.
2. Open Google Antigravity > New Project > Add Folder and select the extracted `CertMaster_Antigravity_Workspace` directory (or open the directory as a project if your Antigravity version offers that).
3. Paste the short kickoff prompt provided with this package. The repository contains both applications, `AGENTS.md`, and a verified static comparison (`docs/integration_audit.md`).

Original source files were collected, not integrated. No live Firebase changes or device-level end-to-end test have been performed. The Google AI Studio hosted project state may differ from these exports if you make further changes there: export/re-sync those changes into the Antigravity working copy before integrating.
